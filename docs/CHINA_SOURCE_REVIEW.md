## 资料适合做什么

地区攻略擅长提供地点、活动、旅行方式、历史体验叙述和规划问题。地图包提供区域线路概览、入口和服务设施线索；“线路”图片中有很多景点分布图、票价表及行李清单，并非全部是自驾路线。

适用顺序是：**发现候选 → 识别活动与负担 → 查证地点及交通方式 → 核验当前条件 → 生成行程**。不能从“资料库覆盖某地区”跳到“产品已经能提供该地区的可执行路线”。

## Emotionapps 的修订结论

保留显著性、效价、觉察的研究参考定位。中国资料带来的变化发生在应用层：

1. 将作者情绪与用户情绪隔离。攻略说“治愈”，只能形成待讨论的体验假设。
2. 将用户感受、活动条件和路线可行性隔离。“想看雪山”不能直接推导适合高强度行程。
3. 保留混合评价与选择权。挑战、期待、担心、成就和疲惫可以并存；不计算净幸福分。
4. 区分谁表达、适用于谁、谁确认。同行者被转述的需求不能冒充本人直接回答。
5. 记录期待、现场和回忆的不同证据。实现一个景观愿望，不等于整段假期轻松或日常幸福提高。

具体规则已写入 [Emotionapps 应用规范](EMOTIONAPPS_FRAMEWORK.md)。

## Prompt 的修订结论

中国版沿用“理解人 → 选择体验 → 核对路线”的简单前台流程，后台补入：来源分层与时效、地点消歧、实际访问节点、交通分段、全日负担、费用口径、完整返程、未知和冲突状态、用户确认后的调整。

来源去重、OCR 质量与事实核验应在检索/校验层实现；道路和日程数值由专门服务计算。语言模型负责结构化理解和说明，不替代这些服务。详见 [中国自驾 Prompt 与 18 个验收场景](CHINA_TRAVEL_PROMPT.md)。

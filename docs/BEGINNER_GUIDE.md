# 自驾自由 2.0 新手教程

## 1. 写下想法

在大框输入下面的示例。主题是帮助表达的分类，不是目的地。

```
现在的感受：想休息
期待的体验：慢慢看山水
在意与顾虑：不想赶路
```

点击“按主题表达”可添加标题，也可以直接输入。

## 2. 填写出行条件

点击橙色“填写出行条件”，展开表单。

```
从哪里出发：成都
哪天出发：选择未来日期
一共几天：3
每天开几个小时：4
```

预算在“随心选择”里填写，单位是整团人民币总预算。

## 3. 生成三套方案

填好后点击黑色“整理我的想法”，等待结果。

```
只需提交一次
无需再次确认需求
无需先手动选景点
```

未填写必要条件时，按页面提示补全，再点击提交。

## 4. 比较三个选择

表格每列是一套方案，每行是一项对比条件。

```
先看目的地与每日安排
再看期待、放松、关系与意义
最后看驾驶、预算和取舍
```

屏幕窄时，在表格内向左滑动，查看右边的方案。

## 5. 核实后再出发

“待核实”表示尚未证明可行，不是推荐你直接出发。

```
车程：需要地图核实
费用：需要真实报价
开放、预约、住宿：需要另行核对
```

不满意时返回上方修改想法或条件，再点“整理我的想法”。

当前模型与地图未接通，输出是待核实草案。截图中的日期为演示历史日期，请使用自己的未来日期。

# 自驾自由 2.0 演示包

启动项目后打开 `/demo/index.html`，可播放五幕截图导览或 MP4；也可以直接打开 `public/demo/index.html` 离线查看。截图与视频在 `public/demo/`。

1. 输入想法并选择表达主题。
2. 展开出行条件，填写出发地、日期、天数、驾驶上限。
3. 点击“整理我的想法”，一次生成三套方案对比。
4. 比较期待、放松、投入、关系、意义、回忆、社区、驾驶、预算和取舍。

演示采用当前真实页面截图拼接，非连续录屏，无配音。窄屏表格支持横向滚动。当前版本为 2.0 功能预览（包版本 2.0.0-alpha.3）；模型和地图缺少密钥，尚未完成真实供应商联调。三套方案为待核实草案，不能作为已满足预算、车程或开放条件的出行承诺。

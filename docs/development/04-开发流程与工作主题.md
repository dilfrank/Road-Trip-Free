本次将聊天整理为工作主题文档，不自动创建或移动新的聊天。每个主题可在以后独立聊天中使用以下任务说明；跨主题的产品变更回写需求基线。

|主题|任务说明|输入|必须交付|
|需求与Prompt|围绕R01–R09完善意图逻辑，不改变已接受交互|01需求文档、Prompt|需求变更、样例、验收条件|

|测试与验收|验证真实流程和数据状态|需求编号、代码SHA|用例、结果、失败记录|
|发布与教程|同步经验证版本并交付新手教程|已通过验收的提交|版本说明、演示、已知限制|

## 每次开发流程
需求编号 → 读相关代码 → 明确验收条件 → 创建单一任务分支 → 实现 → 自动测试 → 页面或真实接口验证 → PR → 合并 → 更新状态和教程。

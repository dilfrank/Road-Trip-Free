## 调用顺序
首页 → POST /api/trip（compare）→ createAlternatives → executeIntent → selectPlaces → 每套 executePlanner → validatePlan → explainPlan/比较内容 → ComparisonTable。
本机资料检索为独立支路；全文检索不等于候选自动抽取，全文搜索结果也没有自动全部进入推荐。

## 五模块现实边界
|模块|已有实现|缺口|
|Intent|结构化接口、显式主题、原话核验|真实模型联调、推断修改与多主体语义|
|Places|八个候选、手动偏好排序、部分同省优先|语义硬约束筛选、全国候选、距离可行性|
|Planner|地图适配、参考往返、停留休息假设|入口与停车坐标、住宿时间窗、多交通接驳|
|Validator|覆盖、返程、驾驶上限、地图数据时效|开放预约、价格、天气与完整个人约束|
|Explainer|核验结果解释及比较字段|所有比较结论严格追溯至核验记录；减少模板化重复|

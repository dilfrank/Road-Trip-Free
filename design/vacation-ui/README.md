## 设计与运行实现

- 首页仅保留品牌、标题、想法输入、“计划”与继续按钮。
- 去掉辅助小字、流程解释、版本角标、装饰画和页脚；后续必要信息用不小于 18px 正文显示，资料说明折叠呈现。
- 出发地点、出发日期、总天数、每日驾驶时长默认隐藏；点击计划展开，可再次收起，值不丢失。
- 条件未完整时点击继续，会自动展开计划并提示缺失项，避免隐藏必填项阻断表单。
- 偏好、结束地点、预算、同行要求置于计划内的“随心选择”；恢复草稿也移入计划。
- 桌面主体宽 720px，移动端单列。保留大片空白，不添加虾图或装饰水墨来填满页面。
- 橙红渐变只集中于计划入口与展开区域；输入文字保持深色，圆角和边框保持克制。
